# woyousha 项目计划文档 (0227版本)

## 1. 项目概述

### 1.1 项目名称
woyousha (中文：我有啥)

### 1.2 项目定位
一款基于 iOS 平台的物品管理应用，将 RPG 游戏的背包管理概念引入现实生活，帮助用户记录、分类、查看和管理个人物品。

### 1.3 核心价值
- **解决痛点**：帮助用户快速找到物品位置，避免重复购买
- **提升效率**：通过 AI 识别和可视化界面，简化物品记录流程
- **增加乐趣**：通过虚拟房间和贴纸式物品展示，让整理变得有趣

## 2. 技术栈选择

### 2.1 开发平台
- **操作系统**：iOS
- **开发语言**：Swift
- **UI 框架**：SwiftUI
- **开发工具**：Xcode

### 2.2 核心技术
- **AI 识别**：豆包大模型 API（物品识别）
- **图像处理**：iOS 原生 Vision 框架（抠图）
- **数据存储**：本地 Core Data + iCloud 同步
- **UI 交互**：SwiftUI 拖拽、动画效果
- **搜索功能**：Siri 集成 + Spotlight 搜索
- **扫码功能**：iOS 原生 AVFoundation 框架

## 3. 核心功能模块

### 3.1 物品记录
- **拍照录入**：调用相机拍摄物品，自动抠图并添加白色描边
- **AI 识别**：通过豆包 API 识别物品信息，自动填充描述
- **扫码录入**：扫描条形码/二维码，自动获取商品信息
- **手动录入**：支持用户手动填写物品信息

### 3.2 物品分类
- **层级结构**：家 -> 容器/家具 -> 物品（简化为单一屋子概念，不需要房间层级）
- **自定义分类**：用户可创建自定义分类（如衣服、工具、药品等）
- **标签系统**：支持为物品添加标签，方便快速筛选

### 3.3 物品查看
- **虚拟屋子**：可视化界面，用户可在虚拟屋子中添加家具，对应真实世界的物品位置
- **列表视图**：传统列表形式，支持排序和筛选
- **搜索功能**：支持关键词搜索、Siri 语音搜索、Spotlight 全局搜索
- **物品详情**：查看物品完整信息，包括图片、描述、分类、数量、耐久度/保质期、位置

### 3.4 智能提醒
- **过期提醒**：药品、食品等物品过期前自动提醒
- **长期未用**：标记长期未使用的物品，建议清理
- **库存不足**：消耗品库存不足时提醒

### 3.5 家庭共享
- **家庭组建**：创建家庭，邀请成员加入（支持非家庭组成员）
- **共同编辑**：成员可共同编辑家庭库存，支持实时同步
- **权限管理**：可设置不同成员的编辑权限（查看/编辑）
- **邀请方式**：通过邮件或短信邀请，无需加入Apple家庭组

### 3.6 数据管理
- **数据同步**：通过 iCloud CloudKit 实现多设备实时同步，支持多人同时编辑
- **共享机制**：使用CloudKit共享数据库，支持非Apple家庭组成员协作
- **数据导出**：支持导出物品清单为 Excel 表格
- **数据备份**：定期自动备份数据

## 5. 准备工作

### 5.1 开发环境
- **Xcode**：从 App Store 下载最新版本
- **iOS 设备**：一台 iPhone（建议 iOS 16+）

### 5.2 API 服务
- **豆包大模型 API Key**：注册火山引擎账号，获取 API Key
- **iCloud 开发者账号**：用于启用 iCloud 同步功能

### 5.3 设计资源
- **SF Symbols**：使用系统自带图标库
- **虚拟房间素材**：初期使用简单 2D 图片或 Emoji

### 5.4 其他
- **测试用户**：招募家庭成员或朋友作为测试用户
- **项目管理工具**：可使用 Trello 或 GitHub Projects 管理开发任务

## 6. 风险与应对策略

### 6.1 风险
- **AI 识别准确性**：豆包 API 识别结果可能不准确
- **性能问题**：大量物品时可能出现卡顿
- **数据安全**：iCloud 同步可能存在数据丢失风险
- **实时同步冲突**：多人同时编辑同一物品时可能产生冲突
- **共享安全**：与非家庭成员共享时的权限管理和数据安全

### 6.2 应对策略
- **AI 识别**：增加人工编辑功能，允许用户修正识别结果
- **性能优化**：实现分页加载、图片压缩等优化措施
- **数据安全**：定期备份数据，提供导出功能

## 7. 预期成果

- 一款功能完整的 iOS 物品管理应用
- 支持 AI 识别和可视化交互
- 实现家庭共享和智能提醒
- 提供良好的用户体验
